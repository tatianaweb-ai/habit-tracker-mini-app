# Трекер привычек — MVP

Веб-приложение для ежедневных привычек в тёплой оранжево-янтарной гамме. Десктопный
layout `max-w-6xl` с двумя колонками, мобильная версия — одна колонка. Без бэкенда:
все данные в `localStorage`. Внутри Telegram работает как Mini App (haptics, `expand()`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Дизайн-система

| Роль | Цвет |
|---|---|
| Основной акцент | `orange-500` / `orange-600` — кнопки, табы, прогресс, полосы |
| Вторичный акцент | `amber-400` / `amber-500` — streak, огонь, градиенты |
| Фон | градиент `orange-50 → amber-50` |
| Карточки | белые, `rounded-2xl`, `shadow-lg shadow-orange-100` |
| Заголовки / подписи | `gray-900` / `gray-600` |
| Выполнено | `emerald-500` (галочка, фон карточки `emerald-50`) |
| Ожидает | `gray-300` |
| Категории | красный (Здоровье), синий (Работа), фиолетовый (Обучение) |

## Структура экранов

**Today** — сетка `lg:grid-cols-3`:
- слева (2/3) — заголовок «Сегодня», кнопка «Добавить привычку» и карточки привычек;
- справа (1/3) — виджеты: большой кольцевой прогресс, текущий streak с огнём,
  лучший streak, процент за неделю и мини-график за 7 дней.

**Stats** — календарь месяца (сетка 7×N, понедельник впереди) с цветными точками,
навигация по месяцам, плитки метрик и список привычек с текущим и рекордным streak.

## Функционал

- отметка выполнения тапом по всей карточке; карточка меняет фон на `emerald-50`,
  галочка появляется с анимацией `scale`;
- автоматический подсчёт current / best streak (сегодняшний день не обнуляет серию);
- создание привычки: название, цель, категория, акцентный цвет (4 тёплых тона);
- удаление — по повторному нажатию (подтверждение);
- 3 демо-привычки с историей за 2 недели при первом запуске;
- `localStorage` (`habit-tracker:v1`) + синхронизация между вкладками;
- Telegram WebApp API подключается опционально, вне Telegram всё работает.

## Проверки

```bash
npm test           # 75 unit + DOM-тестов (Vitest + Testing Library)
npm run test:e2e   # 23 e2e-проверки в реальном Chrome (CDP, без зависимостей)
npm run check      # тесты + дымовой SSR-рендер
npm run build      # прод-сборка
```

`npm run test:e2e` требует запущенного dev-сервера (`npm run dev`).
Чтобы прогнать e2e по прод-сборке: `npm run build && npm run preview -- --port 4173`,
затем `APP_URL=http://localhost:4173/ npm run test:e2e`.
